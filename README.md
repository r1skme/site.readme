# Иван — Gaming Video Editor

Личный сайт-портфолио для отклика на вакансию Short Content Creator / Gaming Video Editor. Визуальный стиль вдохновлён Neverlose Software, но проект независимый и не является официальным сайтом компании.

### Открыть сайт

После включения GitHub Pages в настройках репозитория: **https://r1skme.github.io/site.readme/**

### Публикация на GitHub Pages

Этот репозиторий содержит готовый самостоятельный `index.html` в ветке `main`. Дополнительный сервер, npm и сборка не нужны.

1. Открыть **Settings → Pages** в репозитории.
2. В **Build and deployment** выбрать **Deploy from a branch**.
3. Выбрать `main` и папку `/(root)`, нажать **Save**.
4. Дождаться первого развертывания и открыть ссылку выше.

### Реализация

- Самодостаточная страница HTML со встроенными CSS, JS, шрифтами системного fallback и миниатюрными изображениями логотипов.
- Адаптивность от 320px до десктопа, семантическая разметка и keyboard navigation.
- Аккуратные анимации появления, игровой монтажный таймлайн с управлением паузой и прокруткой, адаптация к `prefers-reduced-motion`.
- Прямые ссылки на YouTube, TikTok и Telegram; копирование Discord.
- Никаких трекеров, внешних JS-библиотек и сгенерированных фотографий/персонажей. Единственный внешний запрос — необязательные Google Fonts, при недоступности используются системные шрифты.

*Примечание:* редакторская сцена в первом экране — интерактивная иллюстрация монтажа, а не запись экрана DaVinci Resolve. Все просмотры TikTok указаны по данным автора портфолио.
